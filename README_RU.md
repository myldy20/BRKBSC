# BRKBSC

**Адаптивный музыкальный компаньон для TrimUI Brick и компьютера.**

BRKBSC слушает голос, инструмент, шум комнаты или любой другой сигнал с микрофона и превращает его в музыкальный материал. У приложения две связанные задачи:

1. **Compose** — напеть фразу и исследовать несколько музыкальных трактовок с отдельно управляемыми гармонией, басом, ритмом и ответной мелодией.
2. **Live** — слушать музыканта во время выступления и выращивать вокруг него сдержанный дрон, пульс и задержанную «тень» исходного звука.

Проект намеренно начинается с прозрачных и лёгких музыкальных алгоритмов. В дальнейшем отдельные решения можно заменить маленькими нейросетями, но только там, где они дадут слышимый музыкальный результат. Мы не пытаемся запустить «Suno на приставке». Мы делаем быстрый, управляемый и надёжный инструмент для TrimUI Brick.

## Текущее состояние

`0.2.0-alpha` — первая версия в логике соавтора. Уже реализованы:

- захват микрофона и воспроизведение через SDL2;
- лёгкое монофоническое определение высоты и атак;
- запись новой фразы в тишине: старая аранжировка автоматически глушится;
- 32-шаговый музыкальный план, разделённый на четыре гармонических участка по содержанию мелодии;
- четырёхголосные аккорды с подбором голосоведения;
- четыре намеренно разные трактовки: **Anchor**, **Reframe**, **Counter** и **Break**;
- отдельные роли Harmony, Bass, Rhythm и Answer;
- фиксация, заглушение и пересборка отдельных ролей;
- Intent Compass: **Faithful ↔ Contrary** и **Still ↔ Driving**;
- live-режим с подмешиванием входа, дроном по высоте, импульсами по атакам и feedback-тенью;
- управление с клавиатуры и SDL-контроллера;
- собственный растровый интерфейс под 1024×768;
- тесты, проверяющие детерминированность и реальное различие четырёх трактовок.

Полный прототип уже заработал и был прослушан на MacBook. На TrimUI Brick приложение пока не проверено. Тембры и Live-режим ещё остаются черновыми; сейчас основной фокус — качество композиционных решений и удобство соавторства.

## Быстрый запуск на macOS

```bash
brew install cmake sdl2
git clone https://github.com/myldy20/BRKBSC.git
cd BRKBSC
git switch prototype/0.1.0-alpha.1
cmake -S . -B build -DCMAKE_BUILD_TYPE=Release
cmake --build build -j
open build/BRKBSC.app
```

При первом запуске macOS должна запросить доступ к микрофону. Если доступ был отклонён, включи его в **Системные настройки → Конфиденциальность и безопасность → Микрофон**.

Тесты ядра без сборки SDL-приложения:

```bash
cmake -S . -B build-core -DBRKBSC_BUILD_APP=OFF
cmake --build build-core -j
ctest --test-dir build-core --output-on-failure
```

## Сценарий Compose

1. Нажми `A` / Space и напой фразу. BRKBSC записывает её в тишине.
2. Нажми `A` / Space ещё раз. Начнёт играть трактовка **Anchor**.
3. Кнопкой `B` последовательно прослушай Reframe, Counter, Break и снова Anchor.
4. Двигай D-pad, меняя Intent Compass. Текущая трактовка будет сразу пересобрана.
5. Выбери роль плечевыми кнопками или `Q` / `E`.
6. Зафиксируй удачную партию кнопкой `Y` / `P`, заглуши её через Select / `M` или пересобери незакреплённый материал через `R`.
7. Клавиши `1`–`4` напрямую выбирают одну из четырёх трактовок.

Зафиксированные роли сохраняются при переключении трактовок и повторной генерации. Запись новой фразы очищает фиксации и mute.

## Управление

| Кнопка | Compose | Live |
|---|---|---|
| `A` / Space | Начать или закончить запись фразы в тишине | Включить или заглушить призрака |
| `B` / Backspace | Следующая трактовка | Стереть память задержки |
| `X` / Tab | Переключить режим | Переключить режим |
| `Y` / `P` | Зафиксировать выбранную роль | Зафиксировать/отпустить высоту дрона |
| L/R shoulder или `Q` / `E` | Выбрать роль | — |
| Select или `M` | Заглушить выбранную роль | — |
| `R` | Пересобрать текущую трактовку, сохранив закреплённые роли | — |
| `1`–`4` | Выбрать Anchor / Reframe / Counter / Break | — |
| D-pad | Intent Compass | BPM / Agency |
| `[` / `]` | Изменить BPM | Изменить BPM |
| Start / Enter | Включить или заглушить звук | Включить или заглушить звук |
| Escape | Выход | Выход |

Реальную раскладку кнопок TrimUI Brick ещё нужно проверить на устройстве.
