# BRKBSC

**Адаптивный музыкальный компаньон для TrimUI Brick и компьютера.**

BRKBSC слушает голос, инструмент, шум комнаты или любой другой сигнал с микрофона и превращает его в музыкальный материал. У приложения две связанные задачи:

1. **Compose** — напеть фразу и получить аккомпанемент: ритм, бас, гармонию и короткий ответный мотив.
2. **Live** — слушать музыканта во время выступления и выращивать вокруг него сдержанный дрон, пульс и задержанную «тень» исходного звука.

Проект намеренно начинается с прозрачных и лёгких музыкальных алгоритмов. В дальнейшем отдельные решения можно заменить маленькими нейросетями, но только там, где они дадут слышимый музыкальный результат. Мы не пытаемся запустить «Suno на приставке». Мы делаем быстрый, управляемый и надёжный инструмент для TrimUI Brick.

## Текущее состояние

`0.1.0-alpha.1` — первый сквозной прототип. Уже реализованы:

- захват микрофона и воспроизведение через SDL2;
- лёгкое монофоническое определение высоты и атак;
- запись напетой фразы;
- оценка тоники и лада;
- генерация 16-шаговых ударных, баса, аккордового пэда и ответной мелодии;
- live-режим с подмешиванием входа, дроном по высоте входного сигнала, импульсами по атакам и feedback-тенью;
- управление с клавиатуры и SDL-контроллера;
- собственный растровый интерфейс без шрифтовых зависимостей под 1024×768;
- тесты ядра, не требующие SDL2.

Полный прототип успешно заработал и был прослушан на MacBook. Теперь он запускается молча, автоматически глушит старую аранжировку во время записи новой фразы и запускает новый план с начала. На TrimUI Brick приложение пока не проверено.

Это всё ещё эксперимент, а не готовый концертный прибор. Детектор высоты монофонический, темп задаётся вручную, а аккомпанемент специально оставлен простым. Следующий этап заменит один общий ответ управляемыми композиционными предложениями с отдельными ролями.

## Быстрый запуск на macOS

```bash
brew install cmake sdl2
git clone https://github.com/myldy20/BRKBSC.git
cd BRKBSC
git switch prototype/0.1.0-alpha.1
cmake -S . -B build -DCMAKE_BUILD_TYPE=Release
cmake --build build -j
open build/BRKBSC.app
```

При первом запуске macOS должна запросить доступ к микрофону. Если доступ был отклонён, включи его в **Системные настройки → Конфиденциальность и безопасность → Микрофон**.

Тесты ядра без сборки SDL-приложения:

```bash
cmake -S . -B build-core -DBRKBSC_BUILD_APP=OFF
cmake --build build-core -j
ctest --test-dir build-core --output-on-failure
```

## Управление

| Кнопка | Compose | Live |
|---|---|---|
| `A` / Space | Начать или закончить запись фразы | Включить или заглушить призрака |
| `B` / Backspace | Сгенерировать другой вариант | Стереть память задержки |
| `X` / Tab | Переключить режим | Переключить режим |
| `Y` / F | Зафиксировать определённую высоту | Зафиксировать/отпустить высоту дрона |
| Start / Enter | Включить или заглушить звук | Включить или заглушить звук |
| D-pad вверх/вниз | Изменить BPM | Изменить BPM |
| D-pad влево/вправо | Изменить самостоятельность | Изменить самостоятельность |
| Escape | Выход | Выход |

Реальную раскладку кнопок TrimUI Brick ещё нужно проверить на устройстве.
